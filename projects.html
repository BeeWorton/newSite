<- Bachelor's thesis project 2026 -> Grade: 5.5 / 6

I evaluated different open-source scanners and one proprietary scanner that scan TLS handshakes for instances of contemporary or legacy cryptography and post-quantum cryptography.

In order to properly test these scanners, I created a container network that provided test cases for endpoints:

  • baseline-classical

    • Contemporary crypto, quantum vulnerable

  • legacy-vulnerable

    • TLS 1.2, expired cert, deprecated algorithm

  • hybrid-pqc

    • X25519MLKEM768 key exchange

  • pure-pqc

    • ML-KEM768 & ML-DSA in use

  • non-nist-pqc

    • FRODOKEM

  • broken-chain

      • Used to check if full chain is parsed
